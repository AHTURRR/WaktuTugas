# Handoff Studio Fokus

1. Baca PRD untuk perilaku, [DESIGN.md](DESIGN.md) untuk visual, dan [design-contract.md](design-contract.md) untuk invariant UI.
2. Buka [galeri sebelum/sesudah](studio-fokus-review.html) untuk melihat hasil nyata, bukan menilai dari nama tema.
3. Semua layar memakai sistem yang sama: Ringkasan, Tugas, Waktu, Jadwal, pratinjau, alasan, sesi/progres, seluruh formulir waktu/tugas, masuk/daftar/konfirmasi, demo dan akun.
4. Periksa [hasil pengujian dan batas](studio-fokus-audit.md). Android fisik, TalkBack, IME Android dan backend hidup memerlukan verifikasi tersendiri.

Dokumen Modern Productivity dan galeri redesign pertama adalah riwayat. Studio Fokus adalah acuan final; jangan menggabungkan kedua palet atau mengembalikan komposisi lama tanpa keputusan desain baru.
